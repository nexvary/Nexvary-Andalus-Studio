# Android Client

Target: Android 15-compatible application using Kotlin and Jetpack Compose.

Planned foundations:
- Arabic-first UI with full RTL layout validation
- English secondary locale, with localization architecture ready for expansion
- Navigation that never exits from inner pages when Back should return
- SceneView/Filament evaluation for 3D/AR
- Capability checks for AR features
- offline project cache and secure API configuration

The Android project will be generated only after the shared design schema and API contract pass the foundation gate, avoiding a UI shell with non-functional buttons.
