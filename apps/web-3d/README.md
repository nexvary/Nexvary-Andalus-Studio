# Web 3D Studio

Planned stack: TypeScript + Three.js.

Responsibilities:
- 2D/3D synchronized floor-plan visualization
- room/wall/opening editing
- Andalusian material and ornament placement
- camera, lighting and GLTF/GLB scene export
- before/after design comparison
- visual regression fixtures

The first implementation will consume `packages/design-schema/andalus-project.schema.json` so web, Android and AI services agree on project semantics.
