# Development Roadmap

## Stage 1 — Foundation
- Monorepo structure
- Shared project schema
- Deterministic SVG pattern engine
- FastAPI service and health endpoint
- Automated tests and CI
- Third-party license register

## Stage 2 — Pattern Studio
- 8/10/12-point stars
- rosettes and strapwork
- repeatable square/hex grids
- borders and corner motifs
- palette presets
- SVG export and dimension metadata

## Stage 3 — 2D Architecture
- walls, rooms, doors, windows and dimensions
- imported floor-plan calibration
- snapping and constraint system
- Arabic labels and RTL UI

## Stage 4 — 3D Studio
- floor-plan extrusion
- doors/windows/openings
- material library
- lighting and camera presets
- GLTF/GLB export

## Stage 5 — Andalusian Style System
- Nasrid / Granada
- Cordoban
- Moroccan-Andalusian
- Mamluk
- Ottoman
- Damascene
- Contemporary Andalusian

## Stage 6 — AI Redesign
- segmentation adapter
- depth adapter
- edge/depth conditioning
- image-to-image and inpainting
- Architectural Lock enforcement
- before/after comparison

## Stage 7 — AR & Capture
- room-scale capture
- plane detection
- placement of arches, tiles and furnishings
- device capability matrix

## Stage 8 — Professional Export
- quantity takeoff helpers
- SVG/DXF pattern exports
- PDF design report
- BIM/IFC bridge evaluation
- contractor-facing specification package

## Release gates
Every stage must pass unit tests, schema validation, RTL checks where applicable, dependency/license review, and visual regression checks before being promoted.
